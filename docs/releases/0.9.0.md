# Lattice 0.9.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026.

- Generate blocks can repeat up to 10 passes, showing each pass its previous answer and stopping early when the answer stops changing.
- Loop wires repeat the section between their endpoints, up to a limit shown on the wire. Generate loops can stop when results stabilize; a Decider key loop that runs out is removed so the Decider can choose another key. Plain prompts cannot loop.
- Loops run at send time. The canvas and preview show only the first pass; estimated request counts include loop passes.
- Generate’s prompt field was renamed **Instruction**. The block and inspector explain whether that instruction follows its wired inputs or, when empty, which wired block supplies it.
- The user-facing name became **Silly Canvas** throughout; the `prompt-canvas` settings key remained the same.

Source: [0.9.0 release](https://github.com/MentallyQuill/Lattice/commit/effaa765145de0cb8f1aadde201e39fa2a9f92cf).
