# Lattice 0.4.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026. **Decider** introduced rule-based branching without a model request.

- Add ordered keys and a fallback. The first matching key wins; rules cover text, length, probability, time, chat details, variables, character and model names, and weighted random choice.
- Each key has an output wire. Blocks on untaken paths are skipped, including Generate blocks, so those paths do not make model requests.
- Preview evaluates rules that do not need generated text. When it cannot decide yet, it follows the fallback and marks that choice provisional.
- The selected path appears on the block, with untaken wires dimmed and the reason shown in the trace and chat. The shared rule editor also added time, chat, and character conditions to blocks.
