# Lattice 0.27.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: October 10, 2026.

This release unifies workflow authoring and story automation in one canvas. Connect model, text, decision, time, event, memory, and document operations to prepare guidance, react to story events, and propose changes to saved story records. Configure model connections and typed node settings in Details, and reuse larger systems as subgraphs.

The examples browser was rebuilt around 30 editable workflows. Lessons cover reply preparation and review, character perspectives, memories, story documents, scheduled events, random outcomes, and reusable systems, with guidance for setting up their connections.
