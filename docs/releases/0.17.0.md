# Lattice 0.17.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 26, 2026.

- Added swipe controls to either rerun Generate blocks for fresh answers or reuse their previous answers when writing a new reply.
- Generate answers can appear folded in chat and move under the completed reply; settings also allow opening them as they arrive or hiding them while keeping them with the message.
- Added the **Passes on down the canvas** Generate setting: its default sends only the block answer onward; enabling it passes along both its wired inputs and its answer.
- Clarified model information shown for profiles.
