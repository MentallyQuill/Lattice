# Lattice 0.30.1

[All release notes](README.md) · [Changes since 0.30.0](https://github.com/MentallyQuill/Lattice/compare/0.30.0...main)

First-use managed files now initialize correctly on existing chat branches when verified parent metadata confirms that the file did not exist there.

## Initialize files on existing branches

- A managed **Read File** can create its first file on an existing branch when the retained parent metadata contains no file. It uses the configured initialization mode, including generation from the current conversation and character.
- The initialized document follows the usual acceptance and save behavior: generated contents are temporary until the result is accepted.
- Existing inherited files still require exact retained branch history. If parent state is missing or deleted, Lattice continues to protect that state rather than treating it as a new file.
- Opening Lattice to check progress after editing a workflow no longer cancels a new run. Edits made while a run is active still cancel it.

## Update

Update Lattice through SillyTavern's **Manage Extensions**, then reload every open SillyTavern page, including mobile browsers.
