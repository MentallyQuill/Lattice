# Lattice 0.26.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: October 9, 2026.

The node shelf was simplified into a compact, searchable collection with clearer purpose icons. Connections gained typed pins and direct wiring, while reroute controls make it easier to organize a graph without changing its underlying workflow.

The Transpose family gains configurable operations: Style Transfer and Format Transfer can use a model, while Terminology Map applies term substitutions without a model request. Nodes can take text or a draft as input, with phase-aware ports and outputs. This release also updated workflow and node terminology across the editor and reference material, and improved handling of older saved workflow identities as the shelf and authoring model changed.
