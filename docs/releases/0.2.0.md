# Lattice 0.2.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026. **Silly Canvas** added controls and live results around prompt generation.

- A button beside Send opens the canvas; when armed it is tinted, and right-click toggles arming. The button can be hidden in settings.
- Generate answers appear in the chat as blocks finish, then fold under the reply. They are display-only and are not added to the saved chat messages.
- Stop cancels Generate blocks that are still running, without retrying or sending them.
- The block trace now follows the order in which prompts are sent, including Generate blocks reached through another block.
- Added cache-busting versions to the manifest and internal imports, with a version-bump helper to keep them aligned.

Source: [0.2.0 release](https://github.com/MentallyQuill/Lattice/commit/e50de72516e795dc65b6cf0d50a32c10655438f0).
