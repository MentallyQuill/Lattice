# Lattice 0.8.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026. Themes now customize the canvas beyond SillyTavern’s colors.

- Choose from six built-in themes: SillyTavern, Dark Night, Blue Moon, Purple Prose, Pink Blink, and Brown Gown. SillyTavern follows the host theme.
- Customize preset colors with live preview, per-color reset, and readability warnings. Colors can be copied and pasted as text to share a theme.
- Deciders gained their own color. Append and prepend wires also gained different dash patterns, so wire types are distinguishable without relying on color.
