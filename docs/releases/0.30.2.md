# Lattice 0.30.2

[All release notes](README.md)

Managed files on existing chat branches continue to work when earlier messages have been edited, deleted or trimmed.

## Branch history and managed files

- Existing branch-owned managed files no longer fail with **BRANCH_POINT_UNAVAILABLE** after earlier chat messages change. Lattice checks fork and history proof when inherited parent state is needed; verified parent absence allows first-use initialization within the same authenticated branch scope.
- Source-bound derived context continues to reset or rebuild from the current accepted conversation when its source changes, rather than using stale history.

## Update

Update Lattice through SillyTavern's **Manage Extensions**, then reload every open SillyTavern page, including mobile browsers, to load version 0.30.2.
