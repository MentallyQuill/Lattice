# Lattice 0.27.4

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: October 15, 2026.

Nodes can now be placed on the canvas before their required settings are complete. Readiness cues distinguish missing setup from missing connections, so authors can lay out a workflow first and configure it afterward.

This release also fills targeted gaps in node capabilities and reduces repeated work in shelf drawers and hover geometry. These changes refine authoring and interaction across the unified editor.
