# Lattice 0.3.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026.

- Each Generate answer in chat gained **What it was asked**, showing the messages and roles sent to the model. Long messages can be expanded; the detail is built on demand and kept in memory rather than stored in the chat file.
- Wiring became easier: larger connection targets, wire-starting from a block’s bottom edge, target highlighting, and snapping near-misses to the closest input.
- Independent blocks run together by default. If a provider rejects the combined request but accepts separate requests, Silly Canvas switches to one at a time, explains the change, and offers a setting to switch back.

Source: [0.3.0 release](https://github.com/MentallyQuill/Lattice/commit/ad74da7e2e43678cb9821f98fb5b31f0117ef9dd).
