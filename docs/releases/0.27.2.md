# Lattice 0.27.2

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: October 13, 2026.

Theme colors now set readable contrasting text on filled accent controls, including when the accent comes from SillyTavern or a custom theme. Run status text is adjusted for contrast on its fields and controls.

Menus, node search, profile pickers, and portal controls now use the workspace theme colors and shared control styling, replacing fixed dark surfaces. Scrollbars in the profile picker also follow theme-specific colors.
