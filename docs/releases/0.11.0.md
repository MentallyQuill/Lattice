# Lattice 0.11.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 24, 2026. Themes gained control over the canvas’s overall visual style.

- Themes can set shapes, fonts, canvas background, wire style, line weight, block headers, and depth as well as colors.
- New presets were SillyTavern, Midnight, Blueprint, Parchment, Neon, Terminal, and Petal. Previous theme names map to their successors.
- The theme editor gained **Change the look**, and shared themes now carry their visual style.
- Themes other than SillyTavern restyle buttons and fields inside the canvas, including for SillyTavern’s light theme.

Source: [0.11.0 release](https://github.com/MentallyQuill/Lattice/commit/3d4c7bfa2c9e5beb01294f7b09e858ce95c73dd4).
