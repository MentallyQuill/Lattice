# Lattice 0.1.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026. The initial import shipped as **Prompt Canvas**, a node canvas for building SillyTavern prompts.

- Build a prompt from Prompt, SillyTavern prompt, Chat history, Injection, Note, and Output blocks. Merge, append, and prepend wires combine their content; vertical position determines reading order.
- Browse SillyTavern prompts and saved library prompts, then place them on the canvas. Save named canvases as JSON, pin one to a chat or character, or set a default.
- Add per-block conditions, including probability, term search, variables, and model name. Preview the compiled messages, token count, warnings, and reasons blocks were included or skipped before sending.
- Keep the extension inactive with the Arm switch off; while armed, the selected canvas builds prompts for chat and text completion.

Source: [initial import](https://github.com/MentallyQuill/Lattice/commit/642c58fedf9e27aa512de938037dbd20af10e6cb).
