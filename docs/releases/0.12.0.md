# Lattice 0.12.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 24, 2026.

- The **State** block defines named values with rules for when to update, stage tables that turn numbers into text, and one output per value. State is calculated from chat each time, avoiding double-counting swipes or deleted messages; values are set manually.
- Added `{{state::}}`, `{{stage::}}`, and `{{statetext::}}` macros, plus a small safe formula language usable in Decider rules and on wires.
- Any wire can have a condition, such as only running when energy is at or below 1.
- Select blocks with Shift-click or Shift-drag and fold them into a group. Groups show incoming and outgoing connections, can be opened and moved as a unit, and work with undo.

Source: [0.12.0 release](https://github.com/MentallyQuill/Lattice/commit/4ce052cbec7245bc7da3b28cca4be55d0782eb49).
