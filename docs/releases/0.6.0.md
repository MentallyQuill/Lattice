# Lattice 0.6.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026. The versioned feature commit is [17a488b](https://github.com/MentallyQuill/Lattice/commit/17a488b3a700629f81c92233b97c1e94c352994b); a later commit with the same version rewrote the README, added the MIT license, and stopped publishing internal notes.

- “Same as the chat” follows the model currently in use. A selected connection profile still supplies its key, endpoint, and preset, but its saved model no longer overrides the live model. If the chat switches provider, that profile is skipped; the block, picker, and preview show the model to be used.
- Switched-off blocks gained a red dashed border, stripes, an **OFF** pill, struck-through text, and dimmed wires. The toggle indicates its on/off state with green or red.
- Chat answers are headed with the block’s name; a custom heading appears beside it.
- Drag a block onto the library to save it, targeting the first folder or a folder it is dropped on.

The manifest lists 0.6.0 twice; these notes use the explicitly versioned feature commit. Later branding and UI details are not applied retroactively.
