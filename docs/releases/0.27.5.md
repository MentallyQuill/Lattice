# Lattice 0.27.5

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: October 16, 2026.

Choose workflow outputs to control which parts of a graph run. Runs include enrolled outputs and their upstream dependencies; older documents infer a primary reply output, and independent side effects can be enrolled in Workflow outputs.

Draft nodes no longer show warning decorations simply because they are unfinished. Structured failure causes remain visible, alongside setup and model indicators. The editor also suppresses hover feedback while a node is being held, reducing distraction during dragging.
