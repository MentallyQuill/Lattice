# Lattice 0.10.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 24, 2026.

- Wires gained **Send what?** filters for selecting messages, extracting tags, stripping thinking, or joining text, plus **Send**, **Activate**, and **Forward result** modes.
- Decider gained every-match, first-match, AI-sorts, and random routing, with multiple outputs, per-input rules, negation, guidance, and a test box.
- The **Lorebook** block reads SillyTavern lorebook entries from wired text, all entries, a constant, or a picked selection. It can filter and limit entries, keep them out of World Info, preview them, and forward entries that fired.
- Other additions include duplicating blocks, highlighting their inputs, icons, token estimates, and warnings for cut-off replies. A dry run in progress no longer lets a real send skip the canvas.
