# Lattice 0.5.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026.

- Generate prompt ordering now follows the height of the block each message came from, even when the message travels through a lower intermediate block. A block’s own text remains after its inputs.
- Generate blocks send their closing instruction as the user turn by default, so providers that move system messages to the top still receive the task in the intended order.
- Decider keys and the fallback gained a **Goes to** picker for routing to one or more blocks.
- Decider rules now include text matching, numeric comparisons (including word, character, message, turn, variable, and d100 values), and an AI yes/no question. The AI rule is only asked when needed; an unclear answer is retried once and then treated as No. Preview does not ask the AI rule.

Source: [0.5.0 release](https://github.com/MentallyQuill/Lattice/commit/97dcc09c64cf4d7b57578c3f100d75e0137f9553).
