# Lattice 0.7.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: September 23, 2026.

- Undo and redo are available through Ctrl+Z, Ctrl+Shift+Z, Ctrl+Y, and canvas header buttons that describe the next action.
- Adding, deleting, wiring, and switching are recorded as single actions; moves are recorded on release and typing after a pause. Text inputs retain the browser’s own Ctrl+Z behavior.
- Deleting a block shows a message that can restore it. Each canvas keeps up to 50 history steps until SillyTavern is reloaded.
