# Lattice 0.25.0

[All release notes](README.md)

Historical notes reconstructed from repository history; controls and names describe this version.

Recorded date: October 9, 2026.

This release brings the canvas editor and subgraph authoring work together. Select a connected section of a workflow to turn it into an editable subgraph, then open it in its own tab and work with typed input and output boundaries. Subgraphs can be saved on the shelf and reused in other workflows.

The canvas now presents node detail according to zoom level, keeping the graph easier to scan while retaining closer detail when zoomed in. Node placement, graph editing, and workflow presentation were also refined as the editor and subgraph experience were integrated.
